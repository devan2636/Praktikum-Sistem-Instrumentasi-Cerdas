# TinyML: Embedded Machine Learning Reference Repository

This repository serves as a comprehensive collection of **TinyML** implementations, specifically curated for the **Smart Instrumentation Systems Laboratory**. It focuses on deploying complex machine learning algorithms onto resource-constrained environments such as microcontrollers and embedded systems.

> **Note:** This repository is a specialized fork and reference collection derived from [thommaskevin/TinyML](https://github.com/thommaskevin/TinyML/). All links have been updated to reflect the current directory structure within this workspace.
